# Deakin University Portal (Sprint 1)

## Project Overview
This project is part of SIT223/SIT753 group assignment. The goal is to redesign the Deakin University website with a modern and user-friendly interface.

## Sprint 1 Work
In this sprint, the team focused on implementing basic UI and structure of the website using HTML, CSS, and JavaScript.

## My Contribution (UI Designer)
- Designed and implemented the website header
- Added Deakin logo to the header
- Updated the header color to a teal green theme
- Improved overall UI styling for better user experience

## Features Implemented
- Navigation bar with multiple sections (Home, News, Programs, Student, Staff)
- Login and Registration system using JavaScript
- Dynamic timetable generation
- Student and Staff portal sections
- Search functionality

## Technologies Used
- HTML
- CSS
- JavaScript
- GitHub (version control)

## Learning Outcome
This project helped me understand how to work in a team using GitHub, how to manage tasks using Trello, and how UI design improves user experience.
